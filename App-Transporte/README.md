# App Transporte

Sistema de gestión de vehículos, conductores y viajes.

## Instrucciones para ejecutar

### Backend
1. Entrar a `backend/`: `cd backend`
2. Configurar el archivo `.env` con las credenciales de MySQL.
3. Instalar dependencias: `npm install`
4. Iniciar servidor: `npm run dev`

### Frontend
1. Entrar a `frontend/`: `cd frontend`
2. Instalar dependencias: `npm install`
3. Iniciar entorno de desarrollo: `npm run dev`
